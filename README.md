# Magic Glass Icon Pack

Тёмный стеклянный icon pack для Honor Magic 7 Pro / MagicOS 9.

## Как получить APK

1. Залейте содержимое этого проекта в GitHub
2. Откройте вкладку **Actions** → workflow **Build APK**
3. Нажмите **Run workflow** (или сделайте push в `main`/`master`)
4. Дождитесь завершения (обычно несколько минут)
5. Скачайте артефакт **MagicGlass-APK**
6. Распакуйте ZIP и установите APK на телефон
7. В Nova / Lawnchair / Niagara выберите тему **Magic Glass**

## Установка сторонних лаунчеров

- [Nova Launcher](https://play.google.com/store/apps/details?id=com.teslacoilsw.launcher)
- [Lawnchair](https://lawnchair.app)
- [Niagara Launcher](https://play.google.com/store/apps/details?id=bitpit.launcher)

## Для стокового лаунчера Honor

Стоковый MagicOS требует формат `.hwt`. Смотрите `hwt_template/` — там описано, как собрать тему.
